# Commissioning Phases at a Glance

| Phase | Typical activities | Key output |
|---|---|---|
| Design | Owner's project requirements review, design review, Cx plan | Cx plan, design review comments |
| Construction | Submittal review, installation inspections, pre-functional checklists | Closed checklists |
| Startup | Vendor startup, individual functional tests | Startup and functional test reports |
| Integrated testing | Integrated systems tests, failure scenarios | IST report, issues log |
| Turnover | Training, documentation, deferred-test tracking | Final Cx report, O&M handoff |
| Operations | Seasonal testing, recommissioning triggers | Updated baselines |
