# Commissioning Phases at a Glance

| Phase | Typical activities | Key output | Cx levels (see the [Commissioning Levels One-Pager](../guides/commissioning-levels.md)) |
|---|---|---|---|
| Design | Owner's project requirements review, design review, Cx plan | Cx plan, design review comments | Before level 1 |
| Construction | Submittal review, factory witness tests, installation inspections, pre-functional checklists | Factory test reports, closed checklists | 1 and 2 |
| Startup | Vendor startup, controls point-to-point checkout, individual functional tests | Startup reports, point-to-point sheets, functional test reports | 3 and 4 |
| Integrated testing | Integrated systems tests, failure scenarios, owner verification | IST report, issues log, Level 5 verification checklist | 5 |
| Turnover | Training, documentation, deferred-test tracking | Final Cx report, O&M handoff, [Turnover and Handover Checklist](../checklists/turnover-handover-checklist.md) | After level 5 |
| Operations | Seasonal testing, recommissioning triggers | Updated baselines | Deferred tests |

Which standard governs each phase is project-specific: [VERIFY: ASHRAE Guideline 0 and Guideline 1.1 section numbers].
