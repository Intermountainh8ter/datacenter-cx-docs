## A. Documentation and readiness
- [ ] Approved submittal on file and matches installed nameplate
- [ ] Installation complete per drawings; deviations recorded
- [ ] Manufacturer startup report received
- [ ] Factory and field test reports received
- [ ] O&M documentation received

## B. Installation checks
- [ ] Mounting, anchoring, and clearances verified
- [ ] Labeling and identification complete
- [ ] Power and control terminations torqued and inspected. Torque values: [VERIFY: manufacturer data and NETA ATS torque table section]
- [ ] Grounding and bonding verified
- [ ] Piping, flushing, and leak checks complete (where applicable)

## C. Electrical verification (where applicable)
- [ ] Insulation resistance test recorded. Acceptance value: [VERIFY: NETA ATS applicable section]
- [ ] Protective device settings match approved coordination study
- [ ] Phase rotation and polarity verified
- [ ] Arc-flash labels applied. Label content: [VERIFY: NFPA 70E labeling section]

## D. Controls and monitoring
- [ ] Points list verified end to end (field device to monitoring screen)
- [ ] Alarm setpoints entered per approved sequence of operations
- [ ] Communications to the monitoring system verified
