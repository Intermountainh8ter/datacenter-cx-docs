# Glossary

| Term | Meaning |
|---|---|
| AHJ | Authority having jurisdiction: the body that enforces the applicable codes for the site |
| Alias page | A short page in this repository that keeps a published link working by pointing to the document's home |
| As-found / as-left | The recorded state of equipment before and after work |
| ATS | Automatic transfer switch |
| Backout | Controlled return to the last known good state |
| BMS / EPMS | Building management system / electrical power monitoring system |
| CDU | Coolant distribution unit: pumps, controls, and a heat exchanger that supply a secondary fluid network (for example, to cold plates) and reject its heat to facility water |
| CMMS | Computerized maintenance management system, which holds asset data, work orders, and maintenance schedules |
| Commissioning authority | The party responsible for planning and directing commissioning on behalf of the owner |
| CRAH / CRAC | Computer room air handler (chilled water) / air conditioner (refrigerant) |
| Cx | Commissioning |
| Dead bus | A de-energized bus. In generator paralleling, only the first unit ready may close onto it; the others synchronize to it |
| Dew point | The temperature at which moisture condenses from the air. Liquid cooling supply temperature is kept above it |
| EOP | Emergency operating procedure |
| EPO | Emergency power off: a control that removes power to equipment in an emergency |
| FAT / FWT | Factory acceptance test / factory witness test (a factory test observed by the buyer) |
| Facility water | The primary water system (for example, chilled or condenser water) that a CDU rejects heat to |
| FPT | Functional performance test |
| Go/no-go | A recorded decision, before work or a test, that all conditions to proceed are met |
| Hold point | A step that needs a named person's approval before proceeding |
| IST | Integrated systems test |
| Level 1 to 5 | Commissioning levels: factory testing, installation, startup, functional testing, integrated testing. See the Commissioning Levels One-Pager |
| Load bank | A controllable test load that draws power and rejects it as heat (air or liquid cooled) |
| LOTO | Lockout/tagout, the control of hazardous energy |
| MOP | Method of procedure |
| N, N+1, 2N | Redundancy notation: capacity needed, one spare unit, two full independent systems |
| OEM | Original equipment manufacturer |
| Override log | A record of every forced point, jumper, simulation, and temporary setting applied during work or testing, signed off when removed |
| Paralleling | Running two or more generators synchronized on a common bus, sharing load |
| PFC | Pre-functional checklist |
| PNR | Point of no return |
| Point-to-point checkout | End-to-end proof that each controls point is wired, scaled, named, and displayed correctly; the entry gate to Level 4 |
| Pre-site plan | Planning completed before travel to site or the start of the window |
| Root cause | The underlying reason a failure happened, established by investigation; required before a retest closes an issue |
| SOO | Sequence of operations |
| SOP | Standard operating procedure |
| STS | Static transfer switch |
| Synchronism check | Protective function (device 25) that allows a breaker to close only when the two sources are in step |
| TCS | Technology cooling system: the secondary fluid network between a CDU and the IT equipment |
| Time to limit | Measured time from loss of cooling to an agreed temperature limit at a stated load; an operations baseline from commissioning |
| UPS | Uninterruptible power supply |
