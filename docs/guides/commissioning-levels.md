# Commissioning Levels at a Glance

Many data center projects organize commissioning into five levels. This is an industry convention, not a single published standard, and the exact definitions vary by owner and project. Always use the definitions in the project's commissioning plan.

| Level | Common name | What happens | Evidence produced |
|---|---|---|---|
| 1 | Factory witness testing | Equipment is tested at the factory before shipment | Factory test reports, punch list |
| 2 | Delivery and installation verification | Equipment is received, inspected, and checked as installed | Receiving inspections, installation checklists |
| 3 | Pre-functional and startup | Each unit is energized and started by the vendor or installer | Startup reports, pre-functional checklists |
| 4 | Functional performance testing | Each system is tested against its sequence of operations | Completed Cx scripts, issues log |
| 5 | Integrated systems testing | All systems are tested together under load and failure scenarios | IST report, final issues log |

## Gates between levels

- A level does not start until the previous level's open issues are closed or accepted in writing.
- Each gate has a named approver.
- Deferred tests (for example, seasonal tests) are logged with an owner and a date.
