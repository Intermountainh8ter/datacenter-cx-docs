# MOP: Diesel Fuel Polishing and Tank Sampling

> Example MOP for cleaning stored diesel fuel with a portable or permanent polishing system while the generators stay available. Adapt to the site fuel system and the service vendor's method.

## 1. Document control
Use the block from the [MOP Template](mop-template.md).

## 2. Purpose and scope
Sample the fuel, circulate it through filtration and water separation, sample again, and return the fuel system to normal. One tank at a time.

## 3. Risk and impact

| Question | Answer |
|---|---|
| Systems affected | Fuel storage and supply to the generators |
| Redundancy during work | Generators stay in auto. Risk: stirred-up sediment reaches engine filters, a valve is left in the wrong position, or a spill occurs |
| Worst credible outcome | Utility loss during polishing with sediment in suspension, blocking generator fuel filters |
| Response | Stop polishing, restore valves (backout); change engine fuel filters; EOP for fuel leak; EOP for loss of utility |

## 4. Pre-site plan
- [ ] Change ticket approved; environmental and fire permits in place where required
- [ ] Fuel system drawing reviewed; every valve to be operated listed with its normal position
- [ ] Tank to be polished chosen so that other tanks can supply all generators during the work, if the design allows
- [ ] Fuel quality requirements and test method agreed: [VERIFY: ASTM D975 fuel quality limits and the site fuel testing program]
- [ ] Sample bottles, labels, and laboratory arranged; sample points agreed (bottom, middle, top)
- [ ] Polishing rig inspected: hoses, couplings, filters, water separator, bonding and grounding leads
- [ ] **Spare generator fuel filters on site for every engine**
- [ ] Spill kit, drain covers, containment, and fire extinguishers staged
- [ ] Waste fuel, water, and used filter disposal arranged with a licensed carrier
- [ ] Leak detection and tank gauging confirmed working
- [ ] Backout reviewed; go/no-go recorded

## 5. Prerequisites (day of work)
- [ ] Generators in auto, no alarms; utility stable; no storms forecast
- [ ] Tank level recorded; no fuel delivery scheduled during the work
- [ ] Monitoring center informed; pre-task briefing held

## 6. Safety
Hazards: flammable liquid, static discharge, spill, slips, vapor in enclosed spaces. Bond and ground the rig before opening the tank. No ignition sources. No tank entry under this MOP.

## 7. Roles and communications
Supervisor, fuel vendor technicians, site verifier (owns valve positions), monitoring contact.

## 8. Procedure steps

| # | Action | Expected response | Reading | Init. | Time |
|---|---|---|---|---|---|
| 1 | Record as-found: tank levels, valve positions against the valve list, alarms, generator status | Record complete | | | |
| 2 | Take "before" samples from the agreed points; label and seal | Samples taken | | | |
| 3 | Check for free water at the tank bottom; remove it if present | Water quantity recorded | | | |
| H1 | **HOLD POINT**: supervisor confirms go | Approval given | | | |
| 4 | Bond and ground the rig; connect suction and return hoses to the agreed points | Connections tight; no leaks | | | |
| 5 | If the design allows, set generator supply to another tank; verifier signs each valve moved | Generators supplied from another tank | | | |
| 6 | Start circulation at low flow; check all connections | No leaks | | | |
| 7 | Increase to the working flow; monitor filter differential pressure and water separated | Within the rig's limits | | | |
| 8 | Circulate for the planned number of tank turnovers; change rig filters as needed | Differential pressure falling or stable; fuel visibly clear | | | |
| 9 | Stop circulation; allow the fuel to settle for the agreed time | Settled | | | |
| 10 | Take "after" samples from the same points | Samples taken | | | |
| 11 | Disconnect hoses; cap connections; remove bonding last | No spill | | | |
| 12 | Return every valve to its as-found position; verifier signs each | Valve list matches step 1 | | | |
| 13 | Check generator fuel supply: day tank levels, pump operation, no air or leak alarms | Normal | | | |
| 14 | Record as-left tank level and compare with step 1 | Loss explained (samples, waste) | | | |

## 9. Backout procedure

**Triggers:** utility disturbance; leak or spill; fuel alarm; rig fault; weather change; safety concern.

This MOP has no point of no return. Fuel removed for waste is not returned.

| If stopped during steps | Backout steps | Expected end state |
|---|---|---|
| 2 to 4 | B1: Disconnect if connected; cap; close tank openings. | As-found |
| 5 to 9 | B2: Stop the rig; close rig valves; disconnect and cap; return every valve to as-found with verifier sign-off; confirm generator fuel supply. | As-found valve lineup; fuel partly polished |
| Generators start during polishing | B3: Do B2 at once. Watch engine fuel filter restriction indicators. Change engine filters if restriction rises, one generator at a time. | Generators running on clean filters |

## 10. Restoration and verification
- [ ] Valve lineup verified by a second person against the valve list
- [ ] Generators in auto; fuel alarms clear; leak detection normal
- [ ] Area clean; waste removed

## 11. Closeout
- [ ] Laboratory results received and compared with requirements; further action raised if they fail
- [ ] Engine fuel filter spares restocked
- [ ] Fuel records updated; change ticket closed
