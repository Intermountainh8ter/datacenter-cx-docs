# IST Readiness Checklist

Use at the go/no-go meeting before integrated systems testing. Any unchecked item needs written acceptance by the owner's representative.

## Completion of earlier levels
- [ ] Factory test reports received and punch items closed
- [ ] Installation and pre-functional checklists closed
- [ ] Vendor startup reports received for every system
- [ ] Functional performance tests passed for power, cooling, controls, fire interfaces
- [ ] Issues log reviewed: no open item that affects an IST scenario

## Documents
- [ ] IST plan and one script per scenario approved
- [ ] Sequences of operation and settings at final revision and loaded
- [ ] Protective device settings match the approved coordination study
- [ ] One-lines and valve charts current and posted

## Facility state
- [ ] Building enclosed; rooms clean; construction dust controlled
- [ ] Permanent power and all redundant paths energized
- [ ] Monitoring system online with trends and alarms working
- [ ] Fire detection and suppression in service, or a fire watch plan approved
- [ ] No other trades working in test areas during IST

## Test resources
- [ ] Load banks installed, tested, and remotely controllable
- [ ] Instruments calibrated; recorders time-synchronized
- [ ] Fuel, water, and consumables for the full program
- [ ] Radios or headsets tested in every room

## People
- [ ] Test director, stop authority, recorders, and safety lead named
- [ ] Vendors confirmed for each test day
- [ ] Operations staff attending, to learn the facility's real behavior
- [ ] Pre-task briefing scheduled each day

## Emergency readiness
- [ ] Backout for each scenario reviewed
- [ ] Emergency contacts and first aid arrangements posted
- [ ] Spare parts for likely failures on site (fuses, belts, filters, control modules as agreed with vendors)
