# EOP: Fuel Leak or Spill

> Example EOP for a diesel fuel system serving standby generators. The site spill plan and local environmental rules govern reporting.

## 1. Document control

| Field | Entry |

| EOP ID and revision | |

| Owner / approver / date | |
| Last drill date | |

## 2. Entry conditions
Fuel leak detection alarm, containment alarm, unexplained tank level drop, fuel smell, or visible fuel.

## 3. Pre-site plan (preparedness)
- [ ] Site spill response plan current, with reporting duties and thresholds from the local environmental regulator
- [ ] Fuel system drawing and valve list posted, showing which valve isolates which section and which generators it feeds
- [ ] Emergency fuel shutoffs labeled and known
- [ ] Spill kits sized for the largest credible spill, staged at tanks, pumps, and generators; drain covers available
- [ ] Spill response contractor and fuel vendor emergency contacts current
- [ ] Leak detection and containment alarms tested on their cycle
- [ ] Spare hoses, gaskets, and fittings for the fuel system in stock

## 4. Immediate actions

| # | Action | Expected response |
|---|---|---|
| 1 | Keep people away; remove ignition sources; no hot work | Area controlled |
| 2 | Find the source without entering pooled fuel or enclosed spaces with vapor | Source known |
| 3 | Stop the flow if it is safe: stop the transfer pump, close the nearest isolation valve | Flow stopped or reduced |
| 4 | Contain: cover drains, place absorbents and booms | Spill not spreading |
| 5 | Notify the shift lead | Acknowledged |

## 5. Follow-up actions

| # | Action | Expected response | Time |
|---|---|---|---|
| 1 | Check the valve list: which generators lose fuel supply from the valve closed? | Effect known | |
| 2 | State remaining generator capacity and run time on unaffected fuel | Recorded and reported | |
| 3 | If a running generator is the source, shut it down only if the remaining units can carry the load, or if the leak is a fire risk | Decision logged | |
| 4 | Estimate the quantity lost from tank gauging | Recorded | |
| 5 | Call the spill contractor if beyond site capability | Mobilized | |
| 6 | Report to the regulator if the site plan requires it | Reported and logged | |
| 7 | Collect used absorbents in sealed, labeled containers | Stored for disposal | |

## 6. Escalation and communication

| When | Who is told | By whom |
|---|---|---|
| At once | Shift lead | Operator |
| Fuel outside containment, or standby capacity reduced | Facility manager, owner, spill contractor | Shift lead |
| Reportable quantity or fuel reaching drains, soil, or water | Regulator, per the site plan | Facility manager |
| Fire or vapor hazard | Fire service | Anyone |

## 7. Do not
- Do not wash fuel into drains.
- Do not start or stop electrical equipment inside a vapor area.
- Do not isolate fuel to all generators at once without the shift lead's decision.
- Do not refill a tank until the leak is found and repaired.

## 8. Backout procedure (return to normal)
- **Conditions:** leak repaired and tested; containment emptied and clean; leak detection reset and working.
- **Steps:** reopen isolation valves one at a time, watching the repair; prime and bleed fuel lines as the engine manufacturer requires; test-run affected generators under the generator run SOP; refill tanks to the site's normal level.
- **Verification:** valve lineup matches the valve list, no alarms, generators in auto, fuel quantity and run time restated.

## 9. After the event
- [ ] Waste removed by a licensed carrier, with records
- [ ] Spill kits and spares restocked
- [ ] Similar fittings and hoses inspected elsewhere
- [ ] Post-event review held; regulator follow-up closed
