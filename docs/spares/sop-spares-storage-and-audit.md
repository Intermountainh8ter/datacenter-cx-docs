# SOP: Critical Spares Storage and Audit

## 1. Document control
Use the block from the [SOP Template](../sop/sop-template.md). Frequency: audit every ____ months; shelf-life check monthly.

## 2. Purpose and scope
Confirm that every critical spare in the register is present, correct, in date, and usable.

## 3. Risk
Low. The risk this SOP controls is discovering during an emergency that a spare is missing, wrong, or dead.

## 4. Pre-site plan
- [ ] Current register exported, sorted by storage location
- [ ] Usage log and open purchase orders since the last audit collected
- [ ] Changes since the last audit listed: equipment replaced, firmware upgrades, end-of-life notices
- [ ] Vendor-held stock: verification requested from each vendor before the audit date
- [ ] Tools ready: labels, static protection, battery tester or charger as needed
- [ ] If an outside auditor or vendor attends, access and escort arranged before travel

## 5. Safety
Manual handling for heavy parts. Static precautions for electronics. Battery handling per the manufacturer.

## 6. Procedure steps

| # | Action | Expected response | Init. |
|---|---|---|---|
| 1 | Count each item at its location | Matches the register | |
| 2 | Check label: part number, revision, compatible tags, dates | Complete and legible | |
| 3 | Check revision and firmware against the installed equipment list | Compatible | |
| 4 | Check shelf-life and replace-by dates | In date; items due within the next period flagged | |
| 5 | Inspect condition: packaging sealed, no corrosion, no damage, desiccant fresh | Good | |
| 6 | Perform storage care: charge spare batteries, rotate shafts, power up electronics if the manufacturer calls for it | Done and dated | |
| 7 | Check storage conditions: temperature, humidity, cleanliness, access | Within the manufacturer's storage limits | |
| 8 | Reconcile the usage log: every part used has a reorder | No gaps | |
| 9 | Verify vendor-held stock responses | Confirmed in writing | |
| 10 | Update the register; raise orders for shortages, expiring items, and incompatible items | Register current | |

## 7. Abnormal conditions
- Critical spare missing or unusable: tell the facility manager the same day; order at expedited lead time; note the exposure on the risk register until it arrives.
- Spare incompatible after an equipment change: quarantine and label it; do not leave it on the shelf.

## 8. Backout procedure

| If stopped at | Do this | End state |
|---|---|---|
| Any point | Return every part to its labeled location, reseal packaging, and record where the audit stopped | Store in order; audit resumes from the recorded point |
| A spare is damaged during handling | Quarantine it, mark the register "not available", and reorder | Register reflects true stock |

## 9. Records
Signed audit sheet, updated register, and the list of actions with owners and dates.
