# Critical Spares Inventory Template

Keep one register. A spreadsheet or maintenance system holds the live data; this page defines the fields.

## Register fields

| Field | Why it matters |
|---|---|
| Item ID | Unique number on the label and the shelf |
| Description | Plain name a new technician would search for |
| Manufacturer and part number | Exact ordering reference |
| Hardware revision and firmware version | Must match the installed equipment |
| Compatible asset tags | Where it can be fitted |
| System | Power, cooling, controls, fire |
| Criticality score and decision | From the scoring worksheet |
| Storage location (room, rack, shelf, bin) | Found in minutes, at night |
| Quantity on hand | Counted at audit |
| Minimum and reorder point | Triggers the purchase |
| Lead time (door to door) | Reviewed yearly |
| Supplier and emergency contact | Who to call |
| Date received | Age of the spare |
| Shelf-life or replace-by date | Rotation planning |
| Storage needs (charge cycle, static protection, rotation) | Keeps the spare usable |
| Last inspected or tested | Confidence the spare works |
| Related procedures (MOP, EOP IDs) | Where it is called for |
| Obsolescence status | Active, last-buy announced, discontinued |
