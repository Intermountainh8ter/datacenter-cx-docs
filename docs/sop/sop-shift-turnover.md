# SOP: Shift Turnover

## 1. Document control
Use the block from the [SOP Template](sop-template.md). Frequency: every shift change.

## 2. Purpose and scope
The incoming shift knows the true state of the facility before the outgoing shift leaves.

## 3. Risk
Information lost at turnover: an abnormal lineup, a tagged-out unit, or a half-finished task that the new shift does not know about.

## 4. Pre-site plan
Before arriving for the shift, or before the turnover meeting:
- [ ] Outgoing lead completes the turnover log
- [ ] Incoming lead reads the previous log and the change calendar for the coming shift
- [ ] Vendors expected during the shift are known, with their approved tickets

## 5. Safety
No turnover during an active switching step or an emergency. Finish the step or stabilize first.

## 6. Procedure steps

| # | Action | Expected response | Init. |
|---|---|---|---|
| 1 | Review system status: power path lineup, generators, UPS, cooling, fire, monitoring | Any item not in normal lineup is listed with the reason | |
| 2 | Review active and acknowledged alarms | Each has an owner and next action | |
| 3 | Review work in progress and open change windows | Status and next step for each | |
| 4 | Review locks, tags, and temporary equipment in place | List matches the field | |
| 5 | Review equipment out of service and remaining redundancy | Stated per system | |
| 6 | Review deliveries, visitors, and vendor activity expected | Listed | |
| 7 | Review spares used and reorders needed | Listed | |
| 8 | Walk down any abnormal item together if time allows | Seen by both leads | |
| 9 | Both leads sign the turnover log | Signed, time recorded | |

## 7. Abnormal conditions
If the incoming lead does not accept the state as described, the outgoing lead stays until it is resolved or escalated.

## 8. Backout procedure

| If stopped at | Do this | End state |
|---|---|---|
| Emergency during turnover | Outgoing lead keeps command until the event is stable, then restarts turnover from step 1 | One person clearly in charge at all times |

## 9. Records
Turnover logs are kept and reviewed by the facility manager.
